Incluye y no incluye

Para que decidas con toda la información a la mano.

Sí incluye

  • Subdominio *.page.pe incluido
  • Certificado SSL gratuito y automático
  • Copias de seguridad automáticas
  • Editor visual para publicar contenido
  • Acceso por FTP

No incluye

  • Dominio propio (.com, .pe u otro)
